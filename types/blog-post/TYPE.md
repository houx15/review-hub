# 审阅框架按文章的层次展开：核心论点 → 目标读者与切入 → 论证 → 事实与引证 → 篇章结构 → 语言与语体。概览写全文的架构，正文批注只处理细节。
aspects:
  - id: point
    name: 核心论点
    ask: 文章要读者接受什么判断，这个判断是否值得写？
    criteria:
      - 核心论点可以用一句话陈述，标题、导语与结尾指向同一个论点
      - 论点有增量：不是读者已经普遍接受的常识，也不是为吸引点击而夸大的说法
      - 标题的承诺与正文实际论证的范围一致
    expert_questions:
      - 能否用一句话陈述本文的核心论点？标题、第一段与最后一段说的是否是同一件事？
      - 一位熟悉这个话题的读者，读之前会怎么想，读之后会改变什么判断？如果什么也不会改变，这篇的价值在哪里？
      - 这一论点与同一话题下已有的代表性文章相比，新在角度、证据还是结论？
      - 标题中的说法，正文是否真正论证了，还是只论证了一个更弱的版本？
    red_flags:
      - 读完无法用一句话复述核心论点
      - 标题的论断强于正文的论证
      - 论点是普遍接受的常识，只是换了措辞
  - id: reader
    name: 目标读者与切入
    ask: 文章写给谁，导语能否让这些读者进入正题？
    criteria:
      - 有明确的目标读者，术语、背景知识与论证深度与之相称
      - 导语在最初几段交代问题与读者的关联，不长时间铺垫
    expert_questions:
      - 目标读者是谁？他们已经知道什么，最可能在哪里感到陌生？
      - 导语用什么理由让读者继续读下去？这个理由对目标读者是否成立？
      - 文中哪些术语或背景，作者默认读者了解而实际上未必？哪些解释对目标读者又是多余的？
      - 正文进入核心论点之前，读者要读多少铺垫？
    red_flags:
      - 导语铺垫过长，第三段之后才进入正题
      - 术语未加解释，或对内行读者做了不必要的解释
      - 写作深度在全文中忽高忽低，目标读者不一致
  - id: argument
    name: 论证
    ask: 论点是否由充分的论据和合理的推理支撑，是否回应了最有力的反对意见？
    criteria:
      - 每个分论点都有事实、案例或推理支撑，推理没有跳步
      - 案例有代表性，或作者说明了它的适用范围
      - 正面回应最有力的反对意见，而不是较弱的版本
    expert_questions:
      - 文中最有力的论据是什么？去掉它，论点还能成立吗？
      - 关键案例是代表一般情况，还是挑选出来的特例？作者是否说明了二者的区别？
      - 从论据到结论之间，哪一步推理是默认而未论证的？
      - 一位持怀疑态度的内行读者最先会提出什么反对？文章是否回应，回应的是否是这条反对意见最强的形式？
      - 文中的因果说法，有没有其他解释同样能说明这些现象？
    red_flags:
      - 分论点只有断言，没有论据
      - 由单个案例推出一般结论
      - 回应的是稻草人式的反对意见
      - 相关关系被写成因果关系
  - id: facts
    name: 事实与引证
    ask: 文章依赖的事实、数据和引语是否准确，引用的研究是否被如实转述？
    criteria:
      - 支撑论点的关键事实与数据准确，并给出可追溯的出处
      - 引语与原文一致，没有脱离语境
      - 转述研究结果时不强于原研究的结论
    expert_questions:
      - 论点依赖的三五个关键事实或数据，出处分别是什么？出处本身是否可靠、是否过时？
      - 引语在原文语境中是否是同一个意思？
      - 转述的研究，原文的样本、方法和结论是什么？文章的转述是否把相关写成因果、把初步结果写成定论？
      - 数据的比较对象与口径是否一致？
    red_flags:
      - 关键数据没有出处
      - 研究结果被转述成比原文更强的结论
      - 引语被截取，意思与原文语境不同
  - id: structure
    name: 篇章结构
    ask: 段落的顺序是否服务于论证，读者能否顺着读完？
    criteria:
      - 段落顺序构成一条连贯的论证线索，每段只处理一个意思
      - 抽象论述与具体例子交替，篇幅分配与各部分的重要性相称
      - 结尾回到核心论点，并给出比开头更进一步的东西
    expert_questions:
      - 为每段写一句概括，连起来是否构成一条通顺的论证？
      - 哪一部分篇幅过长、过于抽象，读者最可能在那里放弃？
      - 有没有与核心论点关系不大的段落？删去后论证是否受损？
      - 结尾是推进了论点，还是只重复开头？
    red_flags:
      - 一段包含几个不相关的意思
      - 中段有大段离题的内容
      - 结尾只是重复开头，或在结尾提出新的论断
  - id: voice
    name: 语言与语体
    ask: 语言是否准确、具体，语气是否与读者和场合相称？
    criteria:
      - 句子清楚具体，没有空话、套话与不必要的修饰
      - 语气与读者和发表场合相称，前后一致
    expert_questions:
      - 哪些句子删去后意思不变？
      - 哪些抽象的概括可以换成具体的例子或数据？
      - 语气是否前后一致？哪里显得居高临下、说教或刻意讨好？
    red_flags:
      - 空话、套话与口号式表述多
      - 长句堆叠，主干不清
      - 语气在论述与煽情之间摇摆

# 博客与评论文章

审阅按文章的层次展开：核心论点、目标读者与切入、论证、事实与引证、篇章结构、语言与语体。核心论点不清楚，后面各层的判断都会失去依据，因此判断从核心论点开始。适用于博客、评论、科普文章、公众号文章与项目介绍。

**审阅分两层。** 概览写全文的架构：核心观点、论证、读者与表达，以及决定文章能否成立的几个关键问题（例如论点缺乏新意、关键论据不成立、最有力的反对意见未被回应）。正文批注只处理具体段落的细节。架构层面的问题写进概览，不散落在正文中。

**审阅者的角色**：一位有经验的评论版编辑，熟悉文章所涉话题。阅读文章，能够取得的来源（文章链接的研究、报道与原始数据）对照核实；不运行代码，不重新计算数据。

**通用要求**
- 写法按 `skills/WRITING.md`：先写事实，再写判断；用正常的书面语言。
- 能修改的由 AI 直接修改（数据与出处不符、转述强于原文、明显的病句与错别字）。需要作者判断或补充材料的写成建议；需要对照来源核实的写成待核实；关于论据或论证的疑问写成值得追问。
- 表述层面的问题每次最多五条，只列出不修改。
- 涉及外部来源时，出处必须可以核实；无法取得来源的标明“待核实”，不编造。

**轻量审阅**只看核心论点、论据、关键事实与段落组织。

## thesis · 核心论点的明确性 · J · 核心论点
- **常见问题**：核心论点在结尾才出现，或始终没有明确说出；标题、导语与结尾说的不是同一件事；文章并列几个论点而不分主次。
- **依据的材料**：文章本身。
- **审阅要点**：用一句话写出核心论点，与标题、第一段和结尾逐一比较；写不出一句话时，说明文章在哪几个论点之间摇摆。
- **作者的参与**：核心论点以作者的意图为准；与文章实际呈现的不一致时，可选择调整论点或调整正文。

## novelty · 论点的新意 · J · 核心论点
- **常见问题**：论点是普遍接受的常识；与同一话题下已有的文章角度相同、论据相同；标题制造的新意在正文中没有兑现。
- **依据的材料**：文章本身；审阅者对该话题已有讨论的了解（提及的具体文章标明“待核实”）。
- **审阅要点**：写出目标读者读前与读后的判断，比较两者的差别；指出文章的增量在角度、证据还是结论。
- **作者的参与**：是否值得写、新意落在哪里由作者判断；新意不足时写入概览的关键问题。

## audience_fit · 目标读者与导语 · J · 目标读者与切入
- **常见问题**：导语铺垫过长；术语未加解释，或默认读者了解特定背景；对内行读者解释基础概念；目标读者在文中前后不一致。
- **依据的材料**：文章本身；作者说明的发表场合与读者（如有）。
- **审阅要点**：以目标读者的身份阅读前三段，标出读者会感到陌生或失去兴趣的位置，判断导语是否交代了问题与读者的关联。
- **作者的参与**：目标读者由作者决定。

## support · 论据的充分性 · J · 论证
- **常见问题**：分论点只有断言；关键案例是特例，未说明适用范围；推理跳步；相关关系写成因果关系。
- **依据的材料**：文章本身。
- **审阅要点**：列出每个分论点及其论据，判断论据能否支撑分论点；指出默认而未论证的推理步骤；对文中的因果说法写出可能的其他解释。
- **作者的参与**：关键论据不足时写成值得追问；补充论据需要作者的材料。

## counter · 对反对意见的回应 · J · 论证
- **常见问题**：没有回应最自然的反对意见；回应的是反对意见较弱的版本；对反方立场的转述不准确。
- **依据的材料**：文章本身；审阅者对该话题争论的了解。
- **审阅要点**：写出一位持怀疑态度的内行读者最先会提出的反对，以其最强的形式陈述，判断文章是否回应、回应是否成立。
- **作者的参与**：是否在文中回应、如何回应由作者判断；无法回应的反对意见写入概览的关键问题。

## fact_check · 关键事实与数据 · V · 事实与引证
- **常见问题**：数据、年份或名称有误；数据已经过时；比较对象或统计口径不一致；研究结果被转述为更强的结论。
- **依据的材料**：文章给出的来源；可以取得的原始数据或原始研究。
- **审阅要点**：只核对论点所依赖的关键事实，在来源中找到出处；转述研究时比较原文的样本、方法与结论。不一致时由 AI 直接修改。
- **作者的参与**：来源无法取得时列入“本次未核查”。

## quotes · 引语与转述的准确性 · V · 事实与引证
- **常见问题**：引语与原文措辞不符；截取引语改变了原意；出处标错；把他人的观点转述成更极端的立场。
- **依据的材料**：被引用的原文。
- **审阅要点**：对每条直接引语和关键转述，在原文中找到对应的句子，判断语境中的意思是否一致。
- **作者的参与**：原文无法取得时列入“本次未核查”。

## flow · 段落组织与节奏 · J · 篇章结构
- **常见问题**：段落顺序打乱了论证线索；一段包含几个意思；中段离题或过于抽象；结尾只重复开头，或在结尾提出新的论断。
- **依据的材料**：文章本身。
- **审阅要点**：为每段写一句概括，判断顺序能否构成连贯的论证；标出读者最可能放弃阅读的位置及原因；提出调整顺序或删减的方案。
- **作者的参与**：结构调整幅度较大时提供可选方案，由作者选择。

## prose · 语言与语气 · J · 语言与语体
- **常见问题**：空话、套话与口号式表述；长句堆叠；抽象概括多而具体例子少；语气前后不一，或显得说教、讨好。
- **依据的材料**：文章本身。
- **审阅要点**：列出最影响阅读的几处，说明问题所在并给出改写示例，保留作者的文风。
- **作者的参与**：风格选择以作者为准；改写只作为建议。
