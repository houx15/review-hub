# review-hub

Review Engine: a set of agent skills plus a local review UI that help a person review
AI-produced work (research reports, research plans, product specs, writing).

If you were only asked to install review-hub, follow `INSTALL.md` and ignore the rest of this file.

Before doing anything in this repo, read:

1. `docs/spec/HANDOFF.md` — how to proceed: constraints, phases, gates, open questions.
2. `docs/spec/review-engine-design.md` — what to build and why.

Work one phase at a time and stop at each gate for the user's approval.
Record design decisions in `docs/spec/DECISIONS.md`.
