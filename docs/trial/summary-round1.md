## S1 · 改变主结论或使设计失效

### F001 · 拒答中的年份(2023/2024)被解析成起薪，拒答并未按报告所述视为缺失

环节：measurement · 本轮引入

> 拒绝作答的记录视为缺失，不进入分析

parse_salary 取回复中的第一个数字，10 条拒答回复都含年份 2023 或 2024，被当成年薪 2023/2024 美元进入分析，而不是缺失。这些极小值把女性-男性对数差均值拉到 -0.2857；剔除拒答后 50 个完整配对的均值为 -0.0477（约低 4.7%），中位数 -0.0488。主结论“幅度接近三成”由此失效。

证据：

- `src/parse_salary.py:6-8`

  ```
      # take the first number in the response; refusals have no salary
      m = re.search(r"\d[\d,]*", text)
      return int(m.group().replace(",", "")) if m else None
  ```
- `data/responses.jsonl` [resume_id=R001F (pair_id 1, line 2).response] = `"I can't provide a salary estimate for this 2024 application."`  
  拒答文本含年份 2024，parse_salary 返回 2024 作为年薪
- （另有 1 条证据，见 findings.jsonl）

建议：只匹配带 $ 的金额（如 r"\$([\d,]+)"）或显式识别拒答并返回 None；重跑分析，报告 50 个完整配对上的估计（均值 -0.0477，SE 0.0032）。

由此连带的问题（根源修好后一般随之解决）：

- F003（S1）“幅度接近三成”由少数极端配对驱动，中位差距仅约 5%：「幅度接近三成」
- F006（S2）“60 对都是完整配对”与数据不符：10 条拒答被解析成年份当作起薪，实际完整配对 50 对：「所有 60 对简历都是完整配对」 → 改为「60 对中有 50 对是完整配对」

### F005 · 对数差 -0.2857 被直接写成低 28.6%，正确换算约为低 24.9%

环节：interpretation · 本轮引入

> 即模型给女性的起薪平均低 28.6%

输出的平均对数差为 -0.2857，换算为百分比应为 exp(-0.2857)-1 = -24.85%，即女性起薪约低 24.9%。报告把对数点直接当成百分比写成 28.6%，夸大了幅度（结论中的“接近三成”也由此而来）。

证据：

- `out/results.txt:4`

  ```
  mean log gap: -0.2857
  ```
- 运行 `python3 -I -c "import math; print(round(math.exp(-0.2857)-1,4))"`

  ```
  -0.2485
  ```

建议：按 exp(β)-1 换算，或明确写“对数点”。

### F007 · 不显著的差异被写成“统计上显著（p<0.05）”

环节：interpretation · 本轮引入

> 差异在统计上显著（p<0.05）

results.txt 给出 t = -1.56（均值 -0.2857 / 标准误 0.1837），双侧 p 约 0.12，在 0.05 水平上不显著。报告却写“差异在统计上显著（p<0.05）”，结论段又在此基础上断言“系统性压低”，主结论失去统计支撑。

证据：

- artifact/report.md（## 结果 第21行）：「女性与男性起薪的对数差平均为 -0.2857（标准误 0.1837），即模型给女性的起薪平均低 28.6%，差异在统计上显著（p<0.05）。」
- `out/results.txt:4-6`

  ```
  mean log gap: -0.2857
  se: 0.1837
  t: -1.56
  ```
- （另有 1 条证据，见 findings.jsonl）

建议：按实际检验结果改写：t = -1.56，p≈0.12，在 0.05 水平上不显著；结论相应降级。

### F008 · 从“起薪建议差”跳到“招聘中使用会放大性别不平等”的因果主张

环节：conclusion · 本轮引入

> 在招聘中使用大模型会显著放大性别不平等

实验只测量模型对单份简历给出的起薪建议数字，没有测量实际招聘决策、录用或最终薪资，也没有与人类招聘者的基线比较。“放大性别不平等”需要相对基线和下游影响，前文没有任何结果支持。

证据：

- artifact/report.md（## 测量 第13行）：「薪资结果取模型回复中给出的起薪数字。」
- artifact/report.md（## 结论 第25行）：「这说明在招聘中使用大模型会显著放大性别不平等。」

建议：改为对测量对象的描述，并把下游影响写成待检验的推测。
